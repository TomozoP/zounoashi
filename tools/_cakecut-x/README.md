# Cake Cut → X（Chrome 拡張）

Cake Cut の「Xに投稿」を押すと、X の投稿画面を開いて
1つ目に「投稿文（動画つき）」と書き出した動画、2つ目に「ツリーの2つ目」を入れます。
投稿ボタンは自分で押します。

## 入れかた（最初に一度）

1. Chrome で `chrome://extensions` を開く
2. 右上の「デベロッパー モード」をオンにする
3. 「パッケージ化されていない拡張機能を読み込む」で、このフォルダ（`tools/_cakecut-x`）を選ぶ

中身を更新したら、同じ画面で拡張の「再読み込み」を押します。

## うまく入らないとき

X の画面の作りが変わると、文や動画が入らなくなることがあります（`x.js` の `data-testid` を見直す）。
拡張がないときの Cake Cut は、今までどおり文だけ入った投稿画面を開きます。
