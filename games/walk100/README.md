# 人生ウォーカー

物理で歩くほど年をとり、100歳（大往生）まで歩くゲーム。
0歳はハイハイ、1歳で立ち上がり、18歳まで背が伸び、年をとると前かがみになって70歳で杖をつく。
年齢は進んだ最長の距離を背の高さで割って足した値で決まる（walk.js の `LIFE`。2で1歳、8.5で18歳、27で70歳、35で100歳）。
20歳になる場所からは上り階段（段の高さ8cm・奥行き35cm）で、70歳になる場所で上りきってその先は平らな道。画面の上に今の年齢を出す（1歳になるまでは〇ヵ月）。空の色と太陽の高さは年齢で朝から夕方へ移る。
眺めは年をとるほど横から背中の側へ回り（100歳でほぼ真後ろ）、90歳を過ぎると画面がだんだん白く飛ぶ。
服は年代で変わる（ロンパース、園児のスモック、小学生とランドセル、学生服、私服、背広とネクタイ、ポロシャツ、カーディガン）。
手前の手に年代の持ち物（通園バッグ、学生カバン、仕事のカバン、ネギの入った買い物袋、70歳から杖）。杖も見た目だけで当たりはない。

## 操作

画面・スペース・ジョイパッドを押すたびに左右が入れ替わって一歩。押している間は足を上げ、離すと前へ伸ばして着く。
← → は左右を選んで押す。Esc で最初から。デバッグ：7キーか、上の年齢のあたりを素早く3回タップで70歳へ飛ぶ。
ハイハイは対角の手足（左手と右脚、右手と左脚）を組にして動かす。杖は左脚と一緒に前へ出す。

転ぶ（頭がつく、立ち歩きで胴・腿・腕がつく、ハイハイで裏返る）と真ん中に「挫折」と出て、1.2秒後にその場で同じ年齢のまま起き上がって続く。
歩き続けないと体の流れを止めきれずに転ぶ。85歳からは車いすに座り、押すたびに前へ押し出されて少しずつ止まる（転ばない）。
100歳で「大往生」（縦書き）。時間は出さない。その下に人生の進み（横が時間、縦が年齢）のグラフを出し、転んだところに「挫折」と付ける。

## 作り

- `walk.js`：cannon-es の剛体と蝶番。前後と上下の面だけで動かす（奥行き方向の移動と、ひねり・横倒しの回転は止める）。
  体を前へ押す力は使わず、関節の回転の力（隣り合う部位に同じ大きさで逆向き）で動く。
  転びにくくするため、腰が着いている足（杖をついていれば杖の先も）の上から外れたときだけ、外から少し引き戻す。杖をついている間は胴の回る速さも少し抑える（`HELP`）。
  階段は体の近くの8段だけ当たりを置いて付け替える。段の手前の角に小さな斜めの面をつけ、階段では腿を高く上げ、杖も一段上へつく（`STAIR`）。
  幼いほど脚と腕を少し短く、胴を少し長くする（`KID`）。見た目では頭を大きく、手足と胴をふっくらさせる（当たりは変えない）。
  小さい体は重力も背の高さに合わせて弱め、大人と同じ間合いで倒れるようにしている（同じ押し方で歩ける）。
  立ち歩きは、立っている脚の股関節で胴の傾きを保ち、振り出す脚は体の流れに合わせて着く位置を少し変える（転びそうな側へ足を出す反射）。
  筋力と動かし方は年齢で毎コマ変え（働き盛りの `ADULT` と杖の老人の `ELDER` を混ぜ、85歳から力が落ちる。幼い子は足首を強く）、
  背が0.5%伸び縮みするか杖を持つ年になると、各部位の角度と速さを引き継いで体を作り直す（細かく作り直して途切れなく育つ）。計算は毎秒480回。
- `scene.js`：Three.js で野の道と人を描く。服・髪の色、ネクタイ・ランドセルは毎コマ年齢に合わせ、おむつ、胸の厚みも少しずつ移る。
  ハイハイから立つときは、四つんばいの姿から立ち姿へ0.8秒かけて見た目を寄せ（顔も前へ回す）、杖は持ち始めにすっと現れる。部位の位置と向きは剛体をそのまま写し、左右の手足を奥行き方向へずらして並べる。
- `index.html`：入力、年齢の進行、音（合成音）、結果、共有。BGM（自作の32小節）は歩いた距離に合わせて進み（止まれば止まる）、100歳でちょうど終わる。

Three.js と cannon-es は `games/random-bowling/vendor/` の写しを読む（どちらも MIT、同じ場所にライセンス）。

## 確認

```
node games/_tools/tests/walk100.js
```

押さなければ0歳・2歳・30歳・90歳の体が転ばないこと、手足が着いてから押す人のまねで大人まで歩け、20歳からの階段を上って100歳まで行けること、
一歩で止まると転んでその場で起き上がること、結果の形（秒）、Esc を見る。
