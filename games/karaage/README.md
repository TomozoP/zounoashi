# 画像揚げ

画像を切り抜いて唐揚げ・天ぷらにする、端末内で動く遊びです。

- 初期画像は鶏肉とエビ。画像選択後は線で囲み、チェックで切り抜きを確定します。
- ドラッグで油に入れて揚げ、外へ出すと加熱が止まります。スペース・Enterでも出し入れできます。
- 保存は1080×1080の透過PNG。PCはダウンロード、対応するスマホは画像共有メニューを使います。
- Xで「#画像揚げ」と正式な共有リンクを投稿できます。
- 公開先：https://www.zounoashi.com/#/game/karaage

確認：node games/_tools/tests/karaage-render.js
