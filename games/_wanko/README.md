# わんこボマー（まだ非公開）

`_` で始まるフォルダは GitHub Pages が公開しません。そのため、このフォルダに入れてある間は
`https://www.zounoashi.com/games/wanko/…` も `games/_wanko/…` も 404 になり、直リンクでも開けません。
このファイル自体も公開されません。

サイトのトップ（`index.html`）の `GAMES` にも入れていないので、公開サイトの一覧には出ず、
ページのソースにも名前が残りません。

## 手元では一覧に出る

`index.html` は、**localhost で開いたときだけ** このフォルダの `local.js` を読みに行きます。
そこに一覧用の1件が書いてあるので、手元では実験場のタブにカードが出て、そのまま遊べます。
公開サイトではこのファイルを読みに行かないので、何も出ません。

手元で試したぶんはプレイ数に数えません（`countsHit` が localhost では何もしません）。

## 公開するとき

1. フォルダの名前を戻す

   ```
   git mv games/_wanko games/wanko
   ```

2. `games/wanko/local.js` の中の1件を、`index.html` の `var GAMES = [` の中、
   実験場のゲームが並んでいるところ（`melos` の行の上）に移す。
   **パスの `_wanko` を `wanko` に直す**のを忘れずに。

   ```js
   { type: "lab", tags: [], id: "wanko", title: "わんこボマー", year: 2026, date: "2026-09-11",
     plays: null, url: "", img: "games/wanko/img/thumb.svg",
     play: "games/wanko/index.html", full: true,
     catch: "次から次へと差し出される爆弾を、導火線が尽きる前に解除しつづける" },
   ```

3. `local.js` を消す（`git rm games/wanko/local.js`）

4. `git add` → `git commit` → `git push origin main`

## 中身のおぼえがき

- タテ画面（横540固定・高さは画面の形に合わせる）、`full: true` で1ページまるごと使う
- 仕掛けは10種類（配線 / 色合わせ / スイッチ / ネジ / ダイヤル / タイミング / ポンプ / 長押し / なぞる / 数字入力）を
  4種類の胴体（球・ケース・ドラム缶・パイプ）で出す。共通のルールは「緑＝触れ」
- 舞台は定食屋（暖簾・短冊・赤提灯・白木のカウンター）。解除した数だけ、左端に朱塗りの皿が積み上がる
- BGMはヨナ抜き音階の短い句を箏の音で流し続ける（`bgmSchedule`）。爆発の間だけ音量を落とす
- 女将の立ち絵は `img/okami.webp`。台の縁でクリップして、向こう側に立っているように見せている
- 女将は中央に立つ。出し終えると**左へはけて**いき、次のは**右から**持って入ってくる（`staff`）。
  入れ替わりの間だけ2人が画面に居る。掛け声の吹き出しは画面の上・中央（y=24に固定、頭とかぶらない）
- **皿が10枚たまるごとに、2ユニット連結の大きいのが出る**（10枚目・20枚目…の区切りちょうど。
  `score >= DUAL_FROM && score % 10 === 0`。運まかせにすると間隔がばらつくので固定にした）。
  この間だけ BGM が倍の速さでにぎやかになり（`bgmHot`）、奥に虹色の女将が10人並んでウェーブする
  （`drawCrowd`。色を回す描画が使えない環境では、色は変わらず並ぶだけ）。
  1つの箱に面板が**縦に2つ**積まれ、**どちらも同時に触れる**（触った点にいちばん近い面が選ばれる。
  キーなら ↑↓ / Tab で持ちかえ）。導火線は箱に1本で2.2倍。片方を解くとその面は暗くなり、
  両方そろってから箱ごと飛んでいく（皿は2枚）。
  下の面がお盆に乗る高さは1台のときと同じで、足りないぶんは上へ伸ばす（女将にかぶってよい。
  掛け声の吹き出しだけは避ける＝`twinScale`）
- 台は `bombs` の配列で持つ。1つずつ `serve → live → done → pass` と進み、`withBomb()` で
  「いまの1つ」に差し替えてから仕掛けを呼ぶ。画面の点は `toLocal()` で面板の中の座標に直す。
  位置は `wavePos()`（箱ぜんたいの動き）×`tf`（面板の割り当て）で決まる
- 選んでいる場所の目印（点線の輪）は、**キーで遊んでいるときだけ**出す（`keyMode`）。
  触って遊ぶぶんには何も出ない
- **押すところの間隔は、スマホ（横375px）で44px以上**になるように取ってある。
  1ゲーム単位 = 0.694px なので、中心から中心まで63単位が目安。
  面板の大きさは仕掛けごとに変えてよい（`g.fr`。省略すると共通の `FACE`）
  - いちばん増えたところ（40個目）で、いちばん近い2つの距離は
    配線49px / 色53px / スイッチ44px / ネジ47px / テンキー44px
  - 数が増えても間隔が取れるよう、配線は切る場所を左右にも振り、色ボタンは2段に分ける
  - なぞるの許容幅は46（32px）。配線は線の上ならどこを触っても切れる（許容26、いちばん近い1本）
