# 100歳ウォーク（仮題）

物理で歩くほど年をとり、100歳まで転ばずに歩けるかを試すゲーム。
0歳はハイハイ、1歳で立ち上がり、18歳まで背が伸び、年をとると前かがみになって70歳で杖をつく。
年齢は進んだ最長の距離で決まる（walk.js の `LIFE`。2.5mで1歳、14.5mで18歳、40.5mで70歳、50.5mで100歳）。
空の色と太陽の高さは年齢で朝から夕方へ移る。

## 操作

画面・スペース・ジョイパッドを押すたびに左右が入れ替わって一歩。押している間は足を上げ、離すと前へ伸ばして着く。
← → は左右を選んで押す。Esc で最初から。
ハイハイは対角の手足（左手と右脚、右手と左脚）を組にして動かす。杖は左脚と一緒に前へ出す。

転ぶ（頭がつく、立ち歩きで胴・腿・腕がつく、ハイハイで裏返る）と、その時の年齢（歳）が結果。100歳まで歩けたら「100歳」。

## 作り

- `walk.js`：cannon-es の剛体と蝶番。前後と上下の面だけで動かす（奥行き方向の移動と、ひねり・横倒しの回転は止める）。
  体を前へ押す力や姿勢を起こす外からの力は使わない。関節の回転の力（隣り合う部位に同じ大きさで逆向き）だけで動く。
  立ち歩きは、立っている脚の股関節で胴の傾きを保ち、振り出す脚は体の流れに合わせて着く位置を少し変える（転びそうな側へ足を出す反射）。
  筋力と動かし方は年齢で毎コマ変え（働き盛りの `ADULT` と杖の老人の `ELDER` を混ぜ、85歳から力が落ちる。幼い子は足首を強く）、
  背が2.5%伸び縮みするか杖を持つ年になると、各部位の角度と速さを引き継いで体を作り直す。計算は毎秒480回。
- `scene.js`：Three.js で野の道と人を描く。服と髪の色は年齢で移る。部位の位置と向きは剛体をそのまま写し、左右の手足を奥行き方向へずらして並べる。
- `index.html`：入力、年齢の進行、音（合成音）、結果、共有。

Three.js と cannon-es は `games/random-bowling/vendor/` の写しを読む（どちらも MIT、同じ場所にライセンス）。

## 確認

```
node games/_tools/tests/walk100.js
```

押さなければ0歳・2歳・30歳・90歳の体が転ばないこと、手足が着いてから押す人のまねで大人まで歩けて100歳に届くこともあること、
押しっぱなしで転ぶこと、結果の形（歳）、Esc を見る。
