# 実験場にゲームを足す

ビルドはありません。ファイルを置いて `index.html` に1行足すだけで公開されます。

## 手順

### 1. フォルダを作る

`games/_template/` をコピーして、ゲームの名前に変える。

```
games/
  _template/        ← 雛形（コピー元。そのままでは一覧に出ません）
  share.js          ← 共通のシェア機能
  あたらしいゲーム/
    index.html      ← ゲーム本体
    img/            ← 画像を使うなら
```

名前は URL に出るので半角英数字にする（例: `mizukiri`）。

### 2. 中身を作る

`index.html` の `UPDATE` `DRAW` `SHARE_TEXT` と書いてある箇所を書き換える。
雛形にはこれらが最初から入っている。

- 960×540 の座標でそのまま描ける（画面サイズや解像度は吸収ずみ）
- タップとスペースキーの両方で同じ操作ができる
- Esc でいつでも最初からやり直せる
- 結果画面と「もう一度」「Xでシェア」のボタン

### 3. サムネイルを置く

`img/games/<名前>.svg`（または .png）。カード一覧に出る絵。

### 4. 一覧に1行足す

`index.html` の `var GAMES = [` の中、実験場のゲームが並んでいるところに追記する。

```js
{ type: "lab", tags: [], id: "mizukiri", title: "ゲーム名", year: 2026, date: "2026-09-06",
  plays: null, url: "", img: "img/games/mizukiri.svg",
  play: "games/mizukiri/index.html", catch: "ひとこと説明" },
```

- `type: "lab"` で実験場タブに入り、`#実験場` のタグが自動で付く
- `id` はフォルダ名と合わせる（`#/game/<id>` というURLになる）
- `play` を書くとサイト内で起動する

これで完了。`https://www.zounoashi.com/#/game/<id>` で遊べるようになる。

## シェアについて

`share.js` を読み込んで `zShare` を呼ぶと、X の投稿画面がリンク付きで開く。

```html
<script src="../share.js"></script>
```

```js
zShare({ text: "40075.0kmの水切りに成功しました #水切り世界一周" });
```

リンクは自動で付く。サイトに埋め込まれている場合は、ゲーム単体のURLではなく
**サイトのゲームページのURL** を共有する。

## 気をつけること

- **キー操作**: ゲームはページに埋め込まれて動くので、キーを受け取るにはゲームに
  フォーカスが要る。開いた直後は自動で渡しているが、ページの他の場所をクリックすると
  外れる。タップだけでも遊べるようにしておくと安全。
- **音**: 音は最初の操作より後でしか鳴らせない。鳴らしっぱなしの音を使うときは、
  画面から離れたときに止める処理を入れる（`水切り世界一周` の実装が参考になる）。
- **更新が反映されないとき**: ブラウザが前のファイルを覚えているだけなので、
  スーパーリロード（Ctrl+Shift+R）で直る。
