# 実験場にゲームを足す

ビルドはありません。ファイルを置いて `index.html` に1行足すだけで公開されます。

## 揃えるかたち

実験場のゲームは、この形で統一します（`_template/` がそのまま雛形です）。

| | |
|---|---|
| 作り | HTML1枚 + canvas。ライブラリなし、ビルドなし |
| 描画 | `W`×`H` の固定座標で描く。画面サイズと解像度はこちらで吸収する |
| 文字 | 頼まれた文字だけを出す。説明・煽り・見出し・ラベルを勝手に足さない |
| 操作 | タップとスペースキーで同じことができる |
| リセット | Esc でいつでも最初から（押しっぱなしでは連発しない） |
| 終わり方 | 結果画面に「もう一度」と「Xでシェア」を出す |
| シェア | `share.js` の `zShare` を使う（Xの投稿画面がリンク付きで開く） |

**ゲームごとに変えてよいところ**

- 画面の縦横比とサイズ（`W`, `H`）。変えたら `index.html` の `GAMES` に
  `aspect: "4 / 3"` のように書いて、埋め込み枠の比率も合わせる（省略時は 16:9）
- 中身、絵、音、操作の意味づけ

**サイト側が用意するもの**（ゲーム側で作らなくてよい）

- タイトルの行に「← 一覧」と「全画面」のボタン
- 開いた時点でゲームにキー入力を渡す
- 全画面表示（対応していない端末では、枠を画面いっぱいに広げる表示で代える）

全画面では画面の縦横比がゲームと違うので、**ゲーム側は自分で中央に収まるようにしておく**。
雛形は `W`, `H` から枠の大きさを決めていて、横長でも縦長でもはみ出さない。

## 手順

### 1. フォルダを作る

`games/_template/` をコピーして、ゲームの名前に変える。

```
games/
  _template/        ← 雛形（コピー元。そのままでは一覧に出ません）
  share.js          ← 共通のシェア機能
  あたらしいゲーム/
    index.html      ← ゲーム本体
    img/            ← 画像を使うなら
```

名前は URL に出るので半角英数字にする（例: `mizukiri`）。

### 2. 中身を作る

`index.html` の `UPDATE` `DRAW` `SHARE_TEXT` と書いてある箇所を書き換える。
雛形にはこれらが最初から入っている。

- 960×540 の座標でそのまま描ける（画面サイズや解像度は吸収ずみ）
- タップとスペースキーの両方で同じ操作ができる
- Esc でいつでも最初からやり直せる
- 結果画面と「もう一度」「Xでシェア」のボタン
- 画面に出す文字は、頼まれたものだけにする（説明や煽りを気をきかせて足さない）

### 3. サムネイルを置く

`img/games/<名前>.svg`（または .png）。カード一覧に出る絵。

### 4. 一覧に1行足す

`index.html` の `var GAMES = [` の中、実験場のゲームが並んでいるところに追記する。

```js
{ type: "lab", tags: [], id: "mizukiri", title: "ゲーム名", year: 2026, date: "2026-09-06",
  plays: null, url: "", img: "img/games/mizukiri.svg",
  play: "games/mizukiri/index.html", catch: "ひとこと説明" },
```

- `type: "lab"` で実験場タブに入り、`#実験場` のタグが自動で付く
- `id` はフォルダ名と合わせる（`#/game/<id>` というURLになる）
- `play` を書くとサイト内で起動する
- 16:9 以外にしたときだけ `aspect: "4 / 3"` のように足す

これで完了。`https://www.zounoashi.com/#/game/<id>` で遊べるようになる。

## シェアについて

`share.js` を読み込んで `zShare` を呼ぶと、X の投稿画面がリンク付きで開く。

```html
<script src="../share.js"></script>
```

```js
zShare({ text: "40075.0kmの水切りに成功しました #水切り世界一周" });
```

リンクは自動で付く。サイトに埋め込まれている場合は、ゲーム単体のURLではなく
**サイトのゲームページのURL** を共有する。

## 気をつけること

- **キー操作**: ゲームはページに埋め込まれて動くので、キーを受け取るにはゲームに
  フォーカスが要る。開いた直後は自動で渡しているが、ページの他の場所をクリックすると
  外れる。タップだけでも遊べるようにしておくと安全。
- **音**: 音は最初の操作より後でしか鳴らせない。鳴らしっぱなしの音を使うときは、
  画面から離れたときに止める処理を入れる（`水切り世界一周` の実装が参考になる）。
- **更新が反映されないとき**: ブラウザが前のファイルを覚えているだけなので、
  スーパーリロード（Ctrl+Shift+R）で直る。

## プレイ数の表示について

カードの「◯◯ plays」は、Googleスプレッドシートで数えています。

- 仕組みは `counter.gs`（スプレッドシートの Apps Script に貼るコード）
- サイト側は `index.html` の `COUNTER_URL` に公開URLを書くだけ
- ゲームページを開いた回数を数える。同じタブで開き直しても二重には数えない
- `GAMES` に `plays` を手書きしたゲームは、そちらの数字が優先される
- ゲームを足したら、そのページが最初に開かれたときに行が自動で増える
  （追加しただけではまだ数字は出ない。一度自分で開けば `1 plays` になる）
- `id` は半角小文字の英数字・ハイフン・アンダースコアのみ（40文字まで、200ゲームまで）。
  大文字や日本語を使うと、エラーも出ずに数えられないので注意

実験場にゲームを足すときは、`id` を決めるだけで自動的に対象になります。
スプレッドシートの `counts` シートに行が増えるので、数字は手で直せます。
