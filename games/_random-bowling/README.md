# レッスルボウルの下書き

赤パンツのレスラーが青パンツのレスラーをジャイアントスイングし、大きなピンへ投げる。
画面・スペース・ジョイパッドを長押しすると回転が加速し、離した瞬間の赤レスラーが向く方向へ投げる。指を動かす必要はない。
角度決め・パワーゲージ・ランダムなボールは使わない。方向の自動補正はしない。

3投の倒した本数を合計する（30点満点）。矢印ガイドは表示しない。正面から左右30度以内に投げたときだけ、直後の0.12秒は30％速、その後0.28秒で通常速度へ戻す。物理とカメラを同じ速度で進める。スコアは奥の黒い壁より上に3投分を常時表示し、投球結果の確定時に更新する。
押している途中の画面切替・入力取消は、投げずに構えへ戻す。

## 作り

- `physics.js`：cannon-es による剛体と関節。青レスラーは11部位、10関節。質量の合計は92。
- `scene.js`：Three.jsで描画。赤は足首を握る姿勢で回転し、青は回転中から剛体の位置・回転をそのまま描く。
- `wrestlers.json`：Blenderで作ったレスラーの部位。パンツ・膝当ては赤と青、ブーツは黒、手首は白。
- `models.json`：Blenderで作った底面の閉じたピン。前の大型ピンから縦横2.5倍（初期から4.5倍）、1本の質量は12。レーン幅は20、長さは50に拡張。
- `index.html`：入力、進行、音、スコア、共有。描画は既存の録画用canvasへ合成する。

回転は毎秒1.8ラジアンから15.4ラジアンへゆっくり加速する。最大は毎秒約2.5回転。3秒で約11.7、6秒で約14.4ラジアンへ達する。
レスラーは赤・青とも1.5倍で、当たり判定・関節・握る位置も同じ倍率。放す速度は `3 + 52 × (回転速度の絶対値 / 15.4)の1.5乗`（最大55）。低速の回転では近くに落ち、最大回転で遠くへ飛ぶ。方向はその瞬間の赤レスラーの正面。青レスラーの揺れには左右されない。離すと足首の拘束だけを外し、赤の正面へ押し出す。部位の位置と回転は保つ。
基本の進行は毎秒180回、衝突は毎秒360回、高速時は720回。回転中も毎秒720回の計算で足首だけを両手へ拘束し、他の部位は自由に揺れる。関節の曲がり角・ねじれを制限し、部位同士の自己衝突は除く。
ピンの傾きが約46度を超えるかレーン外へ落ちると倒れたと数える。飛び方を台本で決める処理は使わない。

カメラは回転中に青レスラーを控えめに追い、投球後に前進し、ピンの手前で止まる。前進上限は36.5、左右の追従上限は2。次の投球では元へ戻る。レスラーには顔と髪を付けない。
下書きの既存URLを保つため、フォルダと手元のIDは `random-bowling` のまま。表示名はレッスルボウル。

## 確認

```
node games/_tools/tests/random-bowling.js
node games/_tools/tests/random-bowling-physics.js
node games/_tools/tests/random-bowling-render.js
```

長押しの加速と最大回転、離した方向、取消、キー・ジョイパッド、3投完走、共有、画面サイズを確認する。
物理の確認では関節の隙間、正面・横・後ろへの投球、毎秒30・60・120枚の結果一致を測る。
画面なしのブラウザではBlender模型の読み込み、スイング、飛行、衝突、カメラ復帰を撮影する。

## 同梱した道具

既存の固定版を引き続き使う。ビルド・npm追加・実行中の外部配信元への接続は不要。

- [cannon-es 0.20.0](https://github.com/pmndev/cannon-es/releases/tag/v0.20.0)：MIT。`vendor/cannon-LICENSE`。
- [Three.js r160](https://github.com/mrdoob/three.js/tree/r160)：MIT。配布版0.160.1。`vendor/three-LICENSE`。

投球位置から先頭ピンまで43.5（従来の1.5倍）。レーンと奥壁も14.5だけ延ばす。
