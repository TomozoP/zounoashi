# レッスルボウルの下書き

赤パンツのレスラーが青パンツのレスラーをジャイアントスイングし、大きなピンへ投げる。
レスラーを中心に指で円を描くと、回した向き・速さに合わせてスイングする。指を離した瞬間の接線方向へ投げる。時計回り・反時計回りの両方に対応。長押しだけでは回らず、止めて待つと勢いが落ちる。スペース・ジョイパッドでは長押しを代替操作とする。
角度決め・パワーゲージ・ランダムなボールは使わない。方向の自動補正はしない。

10投の倒した本数を合計する。スコア欄は結果更新時だけ二秒表示する。
押している途中の画面切替・入力取消は、投げずに構えへ戻す。

## 作り

- `physics.js`：cannon-es による剛体と関節。青レスラーは11部位、10関節。質量の合計は92。
- `scene.js`：Three.jsで描画。赤は足首を握る姿勢で回転し、青は投球後に剛体の位置・回転をそのまま描く。
- `wrestlers.json`：Blenderで作ったレスラーの部位。パンツ・膝当ては赤と青、ブーツは黒、手首は白。
- `models.json`：Blenderで作った底面の閉じたピン。従来から縦横1.8倍、1本の質量は6。
- `index.html`：入力、進行、音、スコア、共有。描画は既存の録画用canvasへ合成する。

指の円運動から回転量と速度を読み取り、毎秒10ラジアンまで反映する。中心付近の小さなぶれは回転に数えない。
放す速度は `12 + 回転速度の絶対値 × 2.7`。方向はその瞬間の接線で、各部位の速度差も引き継ぐ。
基本の進行は毎秒180回、衝突は毎秒360回。関節の曲がり角・ねじれを制限し、部位同士の自己衝突は除く。
ピンの傾きが約46度を超えるかレーン外へ落ちると倒れたと数える。飛び方を台本で決める処理は使わない。

カメラは投げた青レスラーを追ってピンへ寄り、次の投球では元へ戻る。
下書きの既存URLを保つため、フォルダと手元のIDは `random-bowling` のまま。表示名はレッスルボウル。

## 確認

```
node games/_tools/tests/random-bowling.js
node games/_tools/tests/random-bowling-physics.js
node games/_tools/tests/random-bowling-render.js
```

円運動の追従と逆回転、離した方向、取消、キー・ジョイパッド、10投完走、共有、画面サイズを確認する。
物理の確認では関節の隙間、正面・横・後ろへの投球、毎秒30・60・120枚の結果一致を測る。
画面なしのブラウザではBlender模型の読み込み、スイング、飛行、衝突、カメラ復帰を撮影する。
