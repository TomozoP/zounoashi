# なんでも唐揚げ（制作中）

画像に衣と揚げ色を付ける、端末内だけで動く試作です。画像を外へ送らず、追加の素材や外部サービスも読み込みません。

- STARTで開始。左下の写真の絵で画像を選びます。最初は星形で試せます。
- 中央の下向き矢印、鍋のタップ、スペース・Enter・ジョイパッドで油に入れます。同じ操作で引き上げます。
- 8秒で濃いきつね色、11秒を過ぎると焦げ始め、18秒で自動的に引き上げます。
- 結果の下向き矢印で1080×1080のPNGを保存します。丸い矢印は同じ画像でやり直し。Xの絵はページの共有です。画像は自動添付されません。
- Escで最初から。操作を開始する指離しを、油に入れる操作へ流しません。
- PNG・JPEG・WebP・GIF・AVIF・BMP、25MBまで。長辺512に縮めて加工します。GIFは静止画として扱います。
- 透過画像の形を保ち、端につながるほぼ単色の背景を抜きます。複雑な背景の写真は写真全体に衣を付けます。AIで被写体を描き直したり、自動で物体を切り抜いたりはしません。
- iPhoneでの音と保存の操作は実機で未確認です。

検証:

```powershell
node games/_tools/tests/karaage.js
node games/_tools/tests/karaage-render.js
node games/_tools/tests/karaage-render.js /preview/index.html
node games/_tools/tests/preview.js
```

`smoke.js` の「放っておくと結果」は、画像選択後に油へ入れる操作を待つため時間切れになります。専用の確認では操作後の進行まで検証します。

原本はこのフォルダ。固定の確認先は `/preview/`。正式な一覧・共有ページには未登録です。
