# 王将棋の制作元

本体は `../index.html` 一枚で動きます。公開時や起動時のビルドは要りません。

- `王将棋.blend`：blenderMCPで制作した二マスの盤、王将と玉将、三つのカメラ。
- `meshes.json`：Blenderから取り出した盤と王将の頂点・面・色。駒の文字も立体の面です。
- `game.js`：進行と描画の編集元。
- `build.js`：雛形の共通部分、立体、ゲームを一枚のHTMLにまとめ直す制作用の道具。

進行を変更したら、リポジトリの先頭で `node games/_oushogi/_source/build.js` を実行します。
このフォルダもゲーム全体も下書きとして非公開です。

## 決めたこと

先後は同じ確率のくじ。下の駒が自分です。先手なら自分の駒、相手のマスの順に触って一手。
スペースまたはジョイパッドのボタンでも二回の入力で同じ一手を指せます。
後手なら相手が自動で指します。どちらも一手で決着し、同じ一手を三方向から見せます。

くじ2.2秒、相手の思考1.3秒、三つの視点は2.1秒・2.6秒・2.8秒、合計7.5秒です。
盤の押しどころの中心間はゲーム座標で約132〜148、結果ボタンの高さは68です。
表示する文字は、依頼された題名・駒の文字と、承諾済みの「先手」「後手」「勝ち」「負け」「1手」、共通の結果ボタンのみです。

初期カメラは真上から盤全体を見下ろします。盤は幅5.6・奥行5.8・厚さ0.88、八角形の脚付き。
マスの幅2.04・全長4.08は保ち、盤の周囲だけを広げています。
自分は王将、相手は玉将で固定。先後によって取り替えません。
文字は承諾を得て端末の「UD デジタル 教科書体 N」の太字から面を作り、駒に合わせて幅と間隔を調整しました。
画像生成は安全判定の誤検出で失敗したため、生成画像は使用していません。

## 確認

`node games/_tools/tests/oushogi.js` で、先後それぞれのタップ・キー・ジョイパッド操作、
一手だけの決着、三視点、再対局、シェア文、六種類の画面サイズ、Escを確認します。

`node games/_tools/tests/oushogi-view.js` は実ブラウザで開始・三視点・結果の五場面を撮り、一時置き場へ画像を出します。

共通の `smoke.js` は、読み込み・30秒の描画・画面変更・でたらめ入力・リセットを通過します。
「放っておくと結果画面まで行く」だけは、開始と先手の着手を待つゲームなので対象外です。
実際の結果到達は専用の確認で検証しています。
